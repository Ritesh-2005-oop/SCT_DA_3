# Employee Attrition Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze employee attrition patterns and identify the key factors influencing workforce turnover. The dashboard provides insights into attrition by age, gender, department, and educational background, helping organizations make data-driven HR decisions.

## Dataset

The dataset contains employee demographic, departmental, educational, and employment-related information used to analyze attrition trends within an organization.

## Tools Used

* Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Cleaning & Transformation

## Dashboard Features

* Overall Employee Count
* Attrition Count
* Attrition Rate (%)
* Average Monthly Income Analysis
* Attrition by Department
* Attrition by Age Group
* Attrition by Gender
* Attrition by Education Field
* Employee Distribution by Department
* Employee Distribution by Gender

## Key Insights

* Total Employees: 1,470
* Attrition Count: 237
* Attrition Rate: 16.12%
* Employees aged 26–35 contribute the highest attrition.
* Research & Development department has the highest employee attrition.
* Employees working overtime show higher attrition rates.
* Life Sciences has the highest attrition among educational backgrounds.
* Male employees represent a larger share of the workforce and attrition cases.



## Business Value

This dashboard helps HR professionals and business leaders:

* Monitor employee turnover trends.
* Identify high-risk employee segments.
* Improve retention strategies.
* Support workforce planning and decision-making.
